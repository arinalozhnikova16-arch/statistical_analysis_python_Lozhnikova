# Комплексный статистический анализ

## Использованный технологический стек:
- **Язык:** Python
- **Библиотеки:** pandas, numpy, scipy.stats, matplotlib, seaborn
- **Среда:** Jupyter Notebook (VS Code)

## Что было сделано
1. **Очистка данных.** Поиск выбросов с помощью BoxPlot и их удаление с помощью межквартального размаха (IQR)
2. **Описательная статистика.** Построение интервального вариационного ряда, расчёт относительных частот, моды, медианы, коэффициентов асимметрии и эксцесса
3. **Оценивание.** Расчёт точечных и интервальных оценок для генеральной средней, дисперсии и СКО
4. **Проверка гипотез.** Использование критерия согласия Пирсона для проверки гипотез о нормальном, равномерном и показательном распределениях с визуализацией критических областей
5. **Сравнение двух выборок.** Проверка гипотез о равенстве средний и дисперсий с использованием z-критерия t-критерия Стьюдента и F-критерий Фишера

## Выводы
- После очистки данных распределение оказалось близким к нормальному
- Гипотезы о равенстве средних и дисперсий для подвыборок А и Б также не отвергаются, что говорит об их однородноссти
